AKDENİZ SESLİ SAHA V1

Bu paket mevcut Akdeniz SAHA uygulamasından bağımsızdır.

İLK HEDEF
- Yarının iş programını konuşarak almak
- Türkçe konuşmayı metne çevirmek
- Ekip, lokasyon, iş, sorumlu, başlangıç/bitiş ve hedef miktarı ayırmak
- Kullanıcıya kontrol ekranı göstermek
- Taslağı JSON olarak dışarı vermek

ÖNEMLİ
Mikrofon özelliğini test etmek için uygulamayı HTTPS altında veya localhost üzerinde açın.
Doğrudan Google Apps Script HTML Service içine gömmeyin.

SONRAKİ AŞAMA
- Mevcut SAHA personel/makine veritabanıyla eşleştirme
- Günlük rapor sesli akışı
- Onaylanan taslağı mevcut SAHA veritabanına API/Apps Script endpoint üzerinden gönderme
